# 开奖数据工作台（GUI 原型）

## 运行

```bash
uv venv
uv pip install -r requirements.txt
uv run python main.py
```

点击首页底部“登录管理”→“导入登录态”粘贴目标网站 Local Storage 的 `user` JSON；点击“如何获取登录态”查看指引。
登录态保存于当前用户目录 `.lottery-sheet-workflow/auth.json`，文件权限限制为仅当前用户可读写；界面和错误信息不显示完整 token。

## 开奖配置：统一选择 Excel

1. 首页直接显示“开奖配置”，在“历史补录”使用唯一的“选择 Excel”按钮。
2. 默认勾选“使用副本（保留源 Excel）”：在原文件同目录创建 `原文件名_已完成.xlsx`，补录只写副本。
3. 取消勾选：直接补录当前选中的源 Excel。两种模式都只填写 B 列空白，保留已有值。
4. 文件选好后也可切换模式；已建立的源文件/副本对应关系会保存，切回副本时继续使用原副本。两份文件不会互相合并。
5. 同名副本已存在且不是当前已绑定的副本时，程序不会覆盖。若要续用该文件，取消勾选，再通过同一个按钮选择已有副本。
6. “表格信息与模板”自动读取实际补录文件的 H1 / I1，不再单独导入。公式未缓存时显示 `—`，请在 Excel 中计算并保存；模板下载保留。
7. 点击“开始”立即查询并补录一次，随后按“运行配置”的轮询间隔持续自动补录；点击“停止”结束轮询。
8. 补录或轮询期间，文件选择、写入方式、登录态及地址修改锁定。停止后可更改。登录管理弹窗关闭不影响轮询；退出主窗口会停止任务并等待当前请求或写入结束。

运行前请关闭正在编辑的 Excel 文件。设置与写入路径会保留到下次启动。

首页默认大小为 720 × 780；开奖配置不再弹窗。底部“登录管理”集中提供登录态导入、获取指引、清除及网页地址配置。

## 自动投注

在“投注参数”保存延后期数、连续期数、每期每注积分并开启“是否自动投注”后，程序会在 Excel D 列预警值归零时启动或重启一轮投注：

1. 补录新期开奖结果，并按 Excel 公式同等逻辑判断最新一期 D 是否归零；
2. “延后期数”表示跳过多少期：填 0 从下一期开始，填 1 跳过下一期后开始，填 2 跳过后两期后开始；
3. 投注进行中如果再次出现 D=0，旧轮次尚未执行的计划立即作废，并以新的零值重新延后、重新连投。例如 119=0、延后1期、连投3期会投注121–123；若123再次为0，则重新投注125–127；
4. 连续投注期数与积分输入联动：连投3期会显示3个积分框，可分别设置如1、2、5；三个投注期中，每个所选号码分别使用1、2、5积分。新 D=0 重启后从第1期积分重新开始；
5. 每期重新读取当前绑定 Excel 的 H1 尾数和 I1 生肖；
6. 获取宾果六合当前期号、实时赔率和动态 `game_id`；
7. 只构造特码 B 注单（`specialCodeB / guessNumberB`），选择 1–49 后排除 H1 尾数与 I1 生肖对应号码；
8. 每个期号最多尝试一次。即使某期因积分不足被拒绝，该期仍属于当前轮次的连续期数，不会向后多投一期；错误写入“查看日志”。成功投注也会记录期号、全部号码及其对应积分、合计积分和投注进度。

投注状态保存在 `.lottery-sheet-workflow/bet_state.json`。重新保存投注参数会开始一轮新的次数计数。

运行日志按中国时区显示到秒，并持久保存于 `.lottery-sheet-workflow/runtime.log`；软件重启后会重新载入最近 2000 行。单个日志达到 5 MB 时轮转为 `runtime.log.1`。“清除日志”会在确认后同时删除当前日志和轮转备份。

## 告警、缺失开奖与盈亏停投

- 网络离线、接口异常、登录态失效、投注失败和盈亏查询失败会写入日志、播放明显提示音，并通过系统托盘显示具体原因；Windows 下显示在右下角通知区域。
- 网页没有某一期开奖结果时，B 列保持空白；当前模板的 D 列公式会继续在上一期基础上加 1。程序同步时会自动升级旧版生成公式，不改写无法识别的自定义公式。
- 首页显示“今日盈亏”和“刷新盈亏”按钮，数值与网页“今日结果”使用同一数据源：`GET /api/v1/member/issueData/{game_id}` 的 `data.next.totalWin`，不再读取可能与网页不同步的 `getUserInfo.totalWin`。
- “运行配置”分别设置“查询与下注轮询时间间隔”和“查询盈亏值时间间隔”。盈亏定时查询独立运行，不要求发生投注，也不依赖历史开奖轮询；手动按钮仍可随时刷新。
- “投注参数”可分别设置盈利停止值和亏损停止值（均可留空，亏损值填正数）。自动检查达到阈值后，在提交任何投注前立即停止当天自动投注并报警；停止状态锁定到中国时区当天结束。自动查询失败时采用安全停止策略：本轮不投注，并记录原因和告警。

## 开发调试按钮

直接从源码运行 `main.py` 会自动视为开发模式并显示调试入口：

```bash
cd code && uv run python main.py --dev
```

`uv run python main.py` 和 `./run.sh` 同样会自动显示。窗口右下方会出现红色悬浮“调试”按钮，可以分别测试提示音（连续播放三遍）、系统通知、全部告警或停止警报。macOS 使用通知中心，Windows 使用右下角系统通知。打包后的正式程序不会创建该按钮；源码调试时如需强制隐藏，可使用 `LOTTERY_DEV_MODE=0 ./run.sh`。
